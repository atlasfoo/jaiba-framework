- **Project name:** JAIBA Framework
- **Description:** Joint-Operations Artificial Intelligence Behavioral
  Architecture framework — a behavioral architecture (skills, a
  memory model, a subagent battery) that organizes how an AI coding
  agent and a human collaborate on real software projects: how context
  is built and kept true, how work is routed and phased, and how the
  human stays the decision-maker at every significant step.
